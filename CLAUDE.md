# Working on this repository

## Pull requests: review comments come before "ready"

After opening a pull request, or pushing to one, always check it for review
comments before telling the owner it is ready: Codex (chatgpt-codex-connector)
reviews every PR, and people may comment too.

- Read every comment: the inline review threads and the conversation, not
  only the latest.
- For each one, either fix it (reproduce it with a test where possible, then
  push to the same branch) or reply saying plainly why not. Then resolve the
  thread.
- Codex reviews when a PR is opened or marked ready, so its findings can
  arrive a few minutes after. Check again before reporting, and after every
  push that addresses comments. Comment `@codex review` to ask for a fresh
  review of new commits.
- When reporting, say which comments were fixed and which were declined, and
  why.
