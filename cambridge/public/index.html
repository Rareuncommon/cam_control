Cameras on the network

Add a PTZ camera

Panasonic, Sony, Canon and PTZOptics heads are added by IP address. CamBridge asks the camera what it is first; nothing on the camera is changed.

Add many PTZ cameras

For a rack of heads that share one login. List their addresses, find out what answers, then add everything found. The username and password are sent only to the addresses you list.
Separate with commas, spaces or new lines. Any of: 192.168.0.21 · 192.168.0.21-40 · 192.168.0.21-192.168.0.40 · 192.168.0.0/27 (a /24 or smaller) · a host name such as cam-wide.local. Up to 256 addresses.

Added cameras

These are saved and reconnect on their own, in this order everywhere in the panel. Removing one does not change the camera itself.

SKAARHOJ panel

Only one thing can own the panel at a time: either SKAARHOJ Reactor drives the cameras itself, or CamBridge drives them through the panel’s raw panel mode. The switch is made on the panel too — in its web page, System Manager → Settings → Raw Panel Mode — so set it there to match what you choose here.

Who can control the cameras

Operators can drive every camera. Admin is needed for the things that outlast a shoot: adding or forgetting a camera, changing its stored password, and quitting CamBridge.

Bitfocus Companion and other machine clients use a token from the config file instead of a PIN, because they cannot answer a prompt.

Add camera

The login for the camera’s own web page. Leave both blank to keep what is stored.

On the camera: MENU → Network → Network Option → [Access Authen. Info]. Each body has its own username and password — they are not shared, and they cannot be read over the network.

You only enter these once. CamBridge stores them against the camera's MAC address and reconnects on its own from then on.

⚠️ This camera reports access authentication turned off. These bodies will not accept remote control in that state — they connect and drop in a loop. On the camera, set MENU → Network → Network Option → [Access Authen. Settings] back to On, then add it with the username and password from [Access Authen. Info].
